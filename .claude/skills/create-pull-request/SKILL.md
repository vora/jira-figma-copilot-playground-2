When creating a pull request, follow the below instructions:

1. Use the Github MCP
2. In the title of the pull request, always start with "(AI-Generated PR)" so reviewers know the PR was generated with AI
3. Keep the PR description concise, focused, and emoji-free
4. **IMPORTANT**: For now, always open the PR against the "feat/agentic-coding-demo" branch
